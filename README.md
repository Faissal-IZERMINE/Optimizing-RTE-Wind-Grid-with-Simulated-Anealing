# Optimizing-RTE-Wind-Grid-with-Simulated-Anealing

This project was a challenge called 'KIRO', conducted in collaboration with RTE (Réseau de Transport d'Électricité), the electricity transmission provider in France. The primary goal was to optimize an offshore wind grid, focusing on reducing costs. We implemented the simulated annealing algorithm, which consistently produced strong solutions and required minimal in-depth understanding of the physical aspects of the problem.

Each run of the code resulted in effective optimizations, and we primarily used Python throughout the project. This challenge was also part of our Research Operations course.
